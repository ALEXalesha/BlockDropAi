Python, PySide6 и numpy. Без pygame и без PyTorch.

## Режимы

- **Играю сам.** Классические падающие блоки: пять следующих фигур, hold, тень. Кнопка **«Подсказка»** показывает, куда положил бы фигуру ИИ.
- **Играет ИИ.** Пауза, скорость от «как человек» до максимума, счётчик линий.
- **Дуэль с ИИ.** Два поля рядом. Очищенные линии отправляют сопернику мусорные ряды (2 линии - 1 ряд, 3 - 2, 4 - 4). ИИ думает не быстрее заданного для уровня числа фигур в секунду.
- **«Мысли ИИ»** (выключатель в каждом режиме): контуры трёх лучших мест для текущей фигуры с оценками, лучшее - ярче.

## Правила

- Поле 10 × 20 и скрытые ряды над ним.
- 7 фигур из «мешка из 7»: каждые 7 фигур подряд - все разные, порядок случайный.
- Вращение SRS со сдвигами от стен в обе стороны. Таблицы сдвигов считаются из таблиц смещений SRS и в тестах сверяются со стандартными (в том числе T-spin triple, которому нужен пятый сдвиг).
- Мягкое и жёсткое падение, задержка фиксации 0,5 с, которую движение может отложить 15 раз, hold один раз за фигуру.
- 100 / 300 / 500 / 800 очков за 1–4 линии, умноженные на уровень; уровень и скорость растут каждые 10 линий.
- Время игры - от часов, а не от частоты кадров: те же секунды дают ту же партию при 30 и при 144 кадрах в секунду.

## Как играет ИИ

ИИ видит то же, что игрок: поле, текущую фигуру, пять следующих и hold. Он перебирает все места, куда может лечь фигура, и оценивает поле после каждого хода («оценка после хода»).

**Поиск мест.** Поиск по состояниям фигуры (поворот, столбец, ряд) находит все достижимые места, включая подсовы под навес и T-spin, и нажатия, которые туда ведут. Дальше ИИ играет этими клавишами через настоящую партию и никогда не телепортирует фигуру. Закон-тест жмёт эти клавиши в настоящей партии и проверяет, что фигура ложится ровно туда, куда обещал поиск.

**Оценка поля.** Сделаны и сравнены два варианта:

1. **Веса признаков, подобранные методом перекрёстной энтропии (CEM).** Признаки: высота, на которую легла фигура, «съеденные» клетки, переходы по рядам и столбцам, дыры, ряды с дырами, колодцы, неровность, сумма и наибольшая высота столбцов, очищенные линии. Популяция наборов весов играет, лучшие задают следующее поколение.
2. **Маленькая сеть на numpy, обученная TD** в игре с собой, на тех же признаках и высотах столбцов.

В программе используются веса CEM.

**Уровни:**

- **новичок** - ранние веса (после первого поколения);
- **средний** - итоговые веса, без взгляда вперёд;
- **сильный** - итоговые веса, взгляд на следующую фигуру (два хода) и hold.

## Клавиши

Стрелки двигают и вращают, пробел - жёсткий сброс, Z - поворот против часовой, C - hold, Esc - пауза. Любую клавишу можно переназначить в настройках, там же задержка и скорость автоповтора (DAS/ARR).

## Запуск

```
pip install -r requirements.txt
python main.py
```

Обучение запускается только командой и с ограниченным числом потоков:

```
python -m game.train cem --trial            # два поколения и прогноз времени
python -m game.train cem --gens 30 --workers 2
python -m game.train td --trial
python -m game.train export                 # веса CEM в game/models
python -m game.train passport --trial       # прогноз времени паспорта
python -m game.train passport --workers 2
```

## Проверки

`python -m pytest -q`: правила, поиск, признаки, обучение, игрок-ИИ, паспорт и окно (Qt offscreen, без видимых окон). `python tools/mutate.py` нарочно ломает код и проверяет, что тесты ловят каждую поломку.
